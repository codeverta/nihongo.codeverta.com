# Grammar JLPT N4

## Isi kurikulum

44 lesson, 88 unit pola, 176 contoh kalimat, dan 220 soal. Setiap lesson memuat dua unit pola dan lima soal; setiap pola memiliki arti, rumus, penjelasan, kesalahan umum, serta dua contoh Jepang dengan bacaan kana dan terjemahan Indonesia.

Unit pola dapat mengelompokkan beberapa variasi terkait. Materi pengantar mengulang bentuk biasa dan pola N5 yang diperlukan agar latihan N4 dapat diikuti. Pengantar kausatif pasif diberi label pengayaan menuju N3. Kurikulum ini merupakan materi persiapan milik aplikasi, bukan daftar tertutup resmi seluruh pola yang dapat keluar di JLPT. [JLPT FAQ](https://www.jlpt.jp/e/faq/index.html) menjelaskan mengapa daftar spesifikasi isi tes tidak lagi diterbitkan; [ringkasan kemampuan resmi](https://www.jlpt.jp/e/about/levelsummary.html) menjadi acuan tingkat pembelajaran.

Contoh dan soal disusun untuk aplikasi ini. Acuan lanjutan bagi pengajar: [Japan Foundation Irodori Grammar Notes](https://www.irodori.jpf.go.jp/assets/data/Grammar_all.pdf).

## Belajar dan kuis

1. Buka **Belajar → N4 → Grammar**, atau pilih chip N4 pada katalog Grammar.
2. Cari tema atau pola (misalnya `そう`) dan filter bab.
3. Pelajari rumus, penjelasan, contoh, dan kesalahan umum untuk dua pola.
4. Kerjakan lima soal: dua soal bentuk/pemakaian, dua soal pemahaman kalimat, dan satu soal memilih kalimat berdasarkan situasi berbahasa Indonesia.
5. Baca penjelasan setelah mengirim jawaban. Posisi pilihan dirotasi oleh backend.
6. Lulus dengan 4/5 jawaban benar (80%). Nilai terbaik disimpan per lesson; kelulusan pertama memberi 50 XP. Retry tidak menambah XP dan tidak menurunkan nilai terbaik.

Progres kursus N4 dihitung dari lesson N4 yang lulus. Kelulusan N5 tidak menambah progres N4. Bantuan kana berupa baris bacaan lengkap, bukan furigana di atas setiap kanji. Fitur kuis dan progres memakai API yang sama dengan N5, termasuk kepemilikan attempt per pengguna dan hasil penyelesaian yang idempotent.

## Sumber backend dan API

- Materi: `backend/data/grammar/n4.json` (Go embed). Flutter tidak menyimpan materi atau kunci jawaban N4.
- Loader: `backend/internal/store/grammar_n4_content.go`; memastikan tiap lesson memiliki dua pola, dua contoh per pola, dan lima soal dengan empat pilihan berbeda.
- ID lesson: `grammar-n4-01` hingga `grammar-n4-44`.
- `GET /v1/grammar/course?level=N4`: katalog dan progres N4.
- `GET /v1/grammar/course` tetap memilih N5 jika level tidak diberikan.
- `GET /v1/grammar/lessons/{lessonId}`: penjelasan tanpa kunci jawaban.
- `POST /v1/grammar/lessons/{lessonId}/attempts`: membuat kuis.
- `POST /v1/grammar/attempts/{attemptId}/answers`: mengirim `questionId` dan `optionId`.
- `POST /v1/grammar/attempts/{attemptId}/complete`: menyimpan hasil setelah semua soal dijawab.

Katalog menolak level selain N5/N4 dengan 422. Semua endpoint Grammar memerlukan login. Kontrak tersedia di `backend/openapi.yaml`.

## Menjalankan pembaruan

Konten JSON dimuat dengan embed, sehingga backend perlu dibangun/dijalankan ulang setelah materi berubah. Hentikan server lama dengan Ctrl+C, kemudian dari folder `backend`:

```powershell
go run ./cmd/api
```

Dari root project, lihat ID emulator dengan `adb devices`, lalu:

```powershell
flutter run -d emulator-5554 --dart-define=API_BASE_URL=http://10.0.2.2:8080/v1
```

Ganti ID sesuai perangkat yang aktif. Backend masih memakai memori: restart menghapus sesi, attempt, progres, dan XP. Login kembali setelah restart. Lihat [panduan menjalankan project](running-project.md).
