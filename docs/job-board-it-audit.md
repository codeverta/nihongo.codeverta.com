# IT and general job board source audit

Checked 2026-10-18 by ordinary unauthenticated GETs with a normal browser-style user agent. One robots.txt and one homepage were fetched per host and cached under ignored `build/jobs-board-audit/it/`; several allowed detail pages were sampled. HTTP reachability and robots policy are observations, not terms-of-service approval. No login, challenge solving, or access-control bypass was attempted. Retry cadence should be weekly or twice weekly with conditional requests/cache and conservative host rate limits.

## Suggested initial scope

Implement TokyoDev Atom and JapanDev public listing/detail HTML first, then JobsInJapan detail/listing extraction. Keep every fetch to public pages and enforce robots rules per target path. Wantedly's RSS is promising but should be checked once for useful item fields before treating it as an adapter. Do not use endpoint names observed in page scripts as permission to call APIs.
