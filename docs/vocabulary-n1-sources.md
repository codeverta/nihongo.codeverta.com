# Sumber kosakata N1

Dataset ini merupakan kurasi untuk belajar, bukan daftar resmi JLPT. JLPT tidak menerbitkan daftar kosakata resmi untuk ujian saat ini. Pilihan kata dan pembacaan merujuk daftar publik di bawah; arti Indonesia, contoh kalimat, dan pengelompokan disusun untuk aplikasi ini.

- Tanos JLPT N1 resources and vocabulary list, Jonathan Waller: https://www.tanos.co.uk/jlpt/jlpt1/ (diakses 2026-10-20).
- JLPT Sensei N1 vocabulary list: https://jlptsensei.com/jlpt-n1-vocabulary-list/ (diakses 2026-10-20).
- Jepang.org, daftar kosakata N1 berbahasa Indonesia: https://legacy.jepang.org/jlpt/n1/kosa-kata/ (diakses 2026-10-20).

Cakupan: 64 entri pilihan, bukan daftar lengkap atau jaminan kemunculan dalam ujian. Pembacaan yang dicantumkan adalah pembacaan kata umum; beberapa kata memiliki pembacaan atau nuansa lain. Kalimat contoh bersifat ilustratif dan belum ditinjau penutur ahli. Aplikasi menampilkan bacaan kata di atas kosakata berkanji sebagai furigana dan menyediakan tombol untuk menyembunyikannya.
