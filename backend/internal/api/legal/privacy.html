Pembaruan 9 November 2026: ditambahkan penjelasan analitik penggunaan (Firebase Analytics), iklan untuk pengguna gratis di Android (Google AdMob), pilihan bahasa pengumuman, serta cara mengatur ketiganya. Sebelumnya, 17 Oktober 2026: penyimpanan foto profil dan notifikasi opsional melalui Firebase Cloud Messaging.

Kebijakan ini berlaku untuk aplikasi Nihongo Master, API, dan halaman bantuan terkait yang dioperasikan Codeverta. Pertanyaan dan permintaan hak data dapat dikirim ke {{.Email}}.

Data yang diproses dan tujuannya

  • Akun: alamat email, nama tampilan, ID akun, target belajar, serta identitas dan URL foto profil dari Google jika Anda memilih Google Sign-In. Anda juga dapat memilih foto profil dari perangkat; foto dikompres, metadata gambar dihapus, lalu disimpan di Tencent Cloud COS agar dapat ditampilkan dalam aplikasi. Tautan foto dapat dibuka oleh siapa pun yang memilikinya, jadi jangan unggah gambar sensitif. Data digunakan untuk login, profil, dan mengaitkan kemajuan dengan akun. Token autentikasi digunakan untuk menjaga sesi. Kredensial login diproses untuk memverifikasi akses; jangan pernah mengirim password kepada tim dukungan.
  • Aktivitas belajar: kemajuan pelajaran, jawaban dan hasil latihan/ujian, XP, streak, achievement, dan waktu aktivitas digunakan untuk menyediakan pembelajaran dan menampilkan perkembangan. Sebagian sesi latihan dan sesi login bersifat sementara; data kemajuan tertentu disimpan di database.
  • Pembelian: ID/product pembelian, bukti atau token store, status verifikasi, waktu pemeriksaan, dan token akun opak digunakan untuk memberi akses premium, restore, serta mencegah penggunaan bukti transaksi berulang. Nomor kartu dan informasi rekening pembayaran tidak diterima oleh API kami; pembayaran diproses oleh store.
  • Kamus: kata/karakter yang dicari diteruskan ke penyedia kamus ketika diperlukan dan hasilnya disimpan dalam cache bersama. Permintaan kamus tidak menyertakan email atau profil akun, tetapi istilah pencarian tetap diterima oleh penyedia.
  • Notifikasi opsional: jika Anda mengaktifkan pengumuman, Firebase Cloud Messaging (Google) memproses identitas instalasi/perangkat dan metadata pengiriman agar pesan sampai ke HP. Langganan pengumuman bersifat publik dan tidak memuat email, jawaban belajar, atau detail pembelian. Bahasa aplikasi yang Anda pilih menentukan topik pengumuman (Indonesia atau English) yang diikuti perangkat Anda. Preferensi disimpan pada perangkat dan dapat dimatikan melalui pengaturan notifikasi aplikasi atau pengaturan Android. Backend menyimpan draft serta riwayat pengumuman admin, tanpa daftar token perangkat pengguna.
  • Analitik penggunaan (Android): aplikasi Android memakai Firebase Analytics dari Google untuk memahami fitur mana yang paling sering dipakai agar kami dapat memperbaiki aplikasi. Data mencakup layar atau fitur yang dibuka, tab yang dipilih, paket (gratis/premium/lifetime), bahasa aplikasi, ID instansi aplikasi, informasi perangkat dan versi aplikasi, serta perkiraan lokasi tingkat negara/kota dari alamat IP. Kami tidak mengirim email, nama, ID akun, jawaban latihan, atau kata pencarian ke analitik. Anda dapat mematikannya kapan saja di Pengaturan > Bantu tingkatkan aplikasi.
  • Iklan (Android, pengguna gratis): jika iklan diaktifkan, pengguna paket gratis dan tamu di Android melihat iklan banner dan iklan native dari Google AdMob. Google dan mitranya dapat memakai ID iklan perangkat, alamat IP, dan data perangkat atau interaksi iklan untuk menayangkan, membatasi frekuensi, mengukur, dan mencegah penyalahgunaan iklan. Sebelum iklan diminta, aplikasi menampilkan formulir persetujuan Google (UMP) jika diwajibkan di wilayah Anda; pilihan itu dapat diubah di Pengaturan > Pilihan privasi iklan dan ID iklan dapat diatur atau dihapus di pengaturan Android. Pengguna Premium dan Lifetime tidak melihat iklan. Kami tidak mengirim email, nama, ID akun, atau jawaban latihan Anda ke jaringan iklan.
  • Data teknis: server dan penyedia jaringan dapat memproses alamat IP, metadata koneksi, URL permintaan, waktu, serta informasi browser/perangkat yang dikirim dalam permintaan untuk pengiriman konten, keamanan, dan diagnosis. Jangan memasukkan informasi pribadi ke pencarian atau URL.
  • Kontak bantuan: email dan informasi yang Anda kirim digunakan untuk menjawab pertanyaan, memverifikasi kepemilikan akun, dan menangani permintaan data atau pembelian.

Penyimpanan pada perangkat

Aplikasi menyimpan preferensi, status sesi, serta riwayat/favorit kamus tertentu pada perangkat. Hapus data aplikasi dari pengaturan perangkat untuk membersihkan salinan lokal. Menghapus aplikasi saja tidak menghapus akun server atau membatalkan pembelian.

Pihak yang menerima data

Kami menggunakan penyedia infrastruktur hosting/database, Cloudflare untuk pengiriman dan keamanan jaringan, Google untuk login dan pembelian Google Play, serta Apple untuk pembelian pada versi iOS jika digunakan. Tencent Cloud COS dapat melayani aset gambar dan foto profil yang diunggah; Jisho dan layanan sumber kamus menerima kueri kamus yang diperlukan. Google Fonts dapat menerima permintaan font dari versi aplikasi yang mengunduh font. Penyedia tersebut memproses data sesuai layanan dan kebijakan mereka. Data juga dapat diberikan jika diperlukan untuk memenuhi kewajiban hukum atau melindungi keamanan layanan. Google juga menerima data analitik penggunaan melalui Firebase Analytics dan, untuk pengguna gratis di Android saat iklan aktif, data iklan melalui Google AdMob. Kami tidak menjual data pengguna.

Keamanan dan transfer data

Endpoint publik menggunakan HTTPS. Akses database dan backup dibatasi pada operator yang berwenang. Pemrosesan oleh infrastruktur atau penyedia dapat berlangsung di negara selain negara Anda. Tidak ada sistem yang dapat menjamin keamanan mutlak.

Retensi dan penghapusan

Data akun dan kemajuan disimpan selama akun digunakan, sampai Anda meminta penghapusan. Penghapusan akun menghapus foto profil yang diunggah beserta objek fotonya dari COS, profil, kredensial/akun, kemajuan, achievement, dan sesi/attempt yang terkait dari penyimpanan aplikasi aktif. Bukti transaksi minimum, identitas store, product, status, waktu pemeriksaan, dan token opak tetap disimpan tanpa email, nama, atau ID akun lama selama diperlukan untuk restore hak lifetime, rekonsiliasi, dan pencegahan replay. Cache kamus bersama tidak merupakan riwayat akun pribadi.

Salinan backup terbatas dapat masih memuat data historis setelah penghapusan dari sistem aktif. Deployment saat ini tidak memiliki pembersihan backup otomatis atau batas hari kedaluwarsa yang terjadwal. Backup tidak digunakan untuk pemakaian layanan sehari-hari; permintaan penghapusan dari arsip dapat dikirim ke kontak privasi agar diperiksa operator, dan penghapusan akun harus diterapkan kembali jika backup dipulihkan. Korespondensi bantuan disimpan selama penanganan permintaan dan selama diperlukan untuk catatan penyelesaian atau kewajiban hukum.

Kontrol Anda dan anak-anak

Anda dapat memperbarui profil, memakai katalog tamu tanpa akun untuk fitur yang mendukungnya, dan meminta akses, koreksi, atau penghapusan data melalui email. Cara menghapus akun dan data tersedia di aplikasi dan halaman web. Kami tidak meminta tanggal lahir. Orang tua/wali yang mengetahui data anak diberikan tanpa izin yang sesuai dapat menghubungi kami untuk pemeriksaan dan penghapusan.

Perubahan kebijakan

Versi baru diterbitkan pada halaman ini dengan tanggal berlaku. Perubahan material terkait penggunaan data akan dijelaskan melalui saluran layanan yang sesuai.
